Effortlessly Navigate Your Odoo Models

🚀 JetModules presents "Model Navigator", a simple but yet powerful tool that gives you instant access to model views in Odoo with just one click.

  • 🎡 Instant Access: Open model views directly from the ir.model view. You can also access the model view even if no specific view has been created or defined yet.

  • 🚀 Boost Productivity: Save time for developers & administrators.
  • 🔗 Seamless Integration: Works effortlessly with Odoo.
